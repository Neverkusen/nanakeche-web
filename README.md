# nanakeche-web

Nanakeche Web es una plataforma web comunitaria enfocada en la gestión de talleres, la construcción de comunidad y la visibilización de experiencias de sororidad a través de un mapa interactivo.

El proyecto busca fortalecer el tejido social mediante una experiencia digital segura, accesible y centrada en la participación de las usuarias.

## Objetivo del proyecto

Desarrollar una plataforma web que funcione como:
- Gestor de talleres comunitarios.
- Directorio de experiencias de mujeres participantes.
- Mapa interactivo de la sororidad, donde se compartan historias breves asociadas a un lugar.
- Herramienta administrable, con moderación de contenido para garantizar un espacio seguro.

## Alcance

La plataforma incluye:
- Sitio web público para usuarias.
- Panel de administración para gestión de contenidos.
- Sistema de moderación para experiencias enviadas al mapa.
- Base de datos comunitaria editable.

## Tecnologías utilizadas

- **React** – Desarrollo de la interfaz de usuario.
- **Firebase** – Hosting, base de datos (Firestore) y autenticación.
- **Leaflet** – Implementación del mapa interactivo.
- **GitHub** – Control de versiones y trabajo colaborativo.
